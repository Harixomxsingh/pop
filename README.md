## 🌪️ The Problem

Modern social media and short-form algorithms (Reels, TikTok, Shorts) trap users in an overstimulation loop:
1. **Dopamine Crashes**: Rapid spikes followed by sudden mental slumps.
2. **Screen Tunnel Vision**: Holding a phone 10 inches from your eyes locks your vision into stress vigilance.
3. **Directed Attention Fatigue**: Switching contexts every 5 seconds exhausts the prefrontal cortex, leaving you with heavy, sluggish **digital brain fog**.

Traditional blocker apps rely on guilt and willpower. But when your brain is already tired, willpower is at zero. **Pop is a pull sanctuary, not a blocker**—a 2-minute biological reset to down-regulate your nervous system and return you to clear action.

## 🚀 Running Locally

Pop is built with pure Vanilla HTML5, CSS3, and ES6 JavaScript. Zero dependencies, 100% offline-first PWA.

```bash
# Clone the repository
git clone https://github.com/Harixomxsingh/pop.git

# Navigate to the folder
cd pop

# Start a local static server
python3 -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
